## ✨ Fonctionnalités

- **CRUD Complet** pour toutes les entités (films, notes, tags, liens)
- **Relations complexes** entre les tables (one-to-many, many-to-one)
- **Recherche avancée** avec filtres multiples
- **Pagination** intégrée
- **Statistiques** sur les films (moyenne des notes, nombre total de notes)
- **Top films** les mieux notés
- **Validation des données** avec Pydantic
- **Documentation interactive** Swagger UI et ReDoc
- **Gestion des erreurs** HTTP appropriée
- **CORS** configuré pour les requêtes cross-origin
- **Mode WAL** pour éviter les verrouillages de base de données
- **Logging** des requêtes SQL pour le débogage

bash

Options du serveur :

🔌 Endpoints de l'API
🏠 Root
Méthode	Endpoint	Description
GET	/	Page d'accueil avec liste des endpoints disponibles
GET	/health	Vérification de l'état de l'API et de la base de données
🎥 Movies (Films)
Méthode	Endpoint	Description	Paramètres
POST	/movies/	Créer un nouveau film	movieId, title, genres (optionnel)
GET	/movies/	Liste tous les films	skip, limit, search, genre

DELETE	/movies/{movie_id}	Supprimer un film	-
⭐ Ratings (Notes)
Méthode	Endpoint	Description	Paramètres
POST	/ratings/	Ajouter une note à un film	userId, movieId, rating, timestamp
GET	/ratings/	Liste toutes les notes	movie_id, user_id, skip, limit
PUT	/ratings/{user_id}/{movie_id}	Mettre à jour une note	Nouvelles valeurs
DELETE	/ratings/{user_id}/{movie_id}	Supprimer une note	-
🏷️ Tags
Méthode	Endpoint	Description	Paramètres
POST	/tags/	Ajouter un tag à un film	userId, movieId, tag, timestamp
GET	/tags/	Liste tous les tags	movie_id, skip, limit
DELETE	/tags/{user_id}/{movie_id}/{tag}	Supprimer un tag spécifique	-
🔗 Links (Liens externes)
Méthode	Endpoint	Description	Paramètres
POST	/links/	Créer un lien pour un film	movieId, imdbId, tmdbId
GET	/links/{movie_id}	Récupérer le lien d'un film	-
PUT	/links/{movie_id}	Mettre à jour un lien	Nouvelles valeurs
DELETE	/links/{movie_id}	Supprimer un lien	-
📊 Statistiques
Méthode	Endpoint	Description	Paramètres
GET	/stats/movies/{movie_id}	Statistiques détaillées d'un film	-
GET	/stats/top-rated	Top films les mieux notés	min_ratings, limit

Structure des Tables
Table movies

Colonne	Type	Contraintes	Description
movieId	Integer	PRIMARY KEY, INDEX	Identifiant unique du film
title	String	NOT NULL	Titre du film
genres	String	-	Genres (séparés par |)
Table ratings

Colonne	Type	Contraintes	Description
userId	Integer	PRIMARY KEY	Identifiant de l'utilisateur
movieId	Integer	PRIMARY KEY, FOREIGN KEY	Référence vers movies
rating	Float	-	Note (généralement de 0.5 à 5.0)
timestamp	Integer	-	Timestamp Unix
Table tags

Colonne	Type	Contraintes	Description
userId	Integer	PRIMARY KEY	Identifiant de l'utilisateur
movieId	Integer	PRIMARY KEY, FOREIGN KEY	Référence vers movies
tag	String	PRIMARY KEY	Tag appliqué au film
timestamp	Integer	-	Timestamp Unix
Table links

Colonne	Type	Contraintes	Description
movieId	Integer	PRIMARY KEY, FOREIGN KEY	Référence vers movies
imdbId	String	-	Identifiant IMDB (ex: tt0111161)
tmdbId	Integer	-	Identifiant The Movie Database
📝 Exemples d'Utilisation
Avec curl
bash
# 1. Créer un film
curl -X POST "http://localhost:8000/movies/" \
  -H "Content-Type: application/json" \
  -d '{
    "movieId": 1,
    "title": "Inception",
    "genres": "Sci-Fi|Thriller"
  }'

# 2. Ajouter une note
curl -X POST "http://localhost:8000/ratings/" \
  -H "Content-Type: application/json" \
  -d '{
    "userId": 42,
    "movieId": 1,
    "rating": 4.5,
    "timestamp": 1700000000
  }'

# 3. Ajouter un tag
curl -X POST "http://localhost:8000/tags/" \
  -H "Content-Type: application/json" \
  -d '{
    "userId": 42,
    "movieId": 1,
    "tag": "mind-bending",
    "timestamp": 1700000000
  }'

# 4. Ajouter un lien
curl -X POST "http://localhost:8000/links/" \
  -H "Content-Type: application/json" \
  -d '{
    "movieId": 1,
    "imdbId": "tt1375666",
    "tmdbId": 27205
  }'

# 5. Récupérer le film avec tous ses détails
curl "http://localhost:8000/movies/1"

# 6. Rechercher des films
curl "http://localhost:8000/movies/?search=inception&genre=Sci-Fi"

# 7. Obtenir les statistiques
curl "http://localhost:8000/stats/movies/1"

# 8. Voir le top 10 des films
curl "http://localhost:8000/stats/top-rated?min_ratings=5&limit=10"
Avec Python Requests
python
import requests
import time

BASE_URL = "http://localhost:8000"

# Créer un film
movie_data = {
    "movieId": 2,
    "title": "The Matrix",
    "genres": "Action|Sci-Fi"
}
response = requests.post(f"{BASE_URL}/movies/", json=movie_data)
print(response.json())

# Ajouter plusieurs notes
for user_id in [1, 2, 3]:
    rating_data = {
        "userId": user_id,
        "movieId": 2,
        "rating": 4.0 + user_id * 0.3,
        "timestamp": int(time.time())
    }
    requests.post(f"{BASE_URL}/ratings/", json=rating_data)

# Récupérer les statistiques
stats = requests.get(f"{BASE_URL}/stats/movies/2").json()
print(f"Moyenne des notes: {stats['avg_rating']}")
print(f"Total notes: {stats['total_ratings']}")
Avec JavaScript Fetch
javascript
// Créer un film
fetch('http://localhost:8000/movies/', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({

// Récupérer tous les films
fetch('http://localhost:8000/movies/?limit=5')
    .then(res => res.json())
    .then(movies => {
        movies.forEach(movie => {
            console.log(`${movie.movieId}: ${movie.title}`);
        });
    });

// Ajouter une note avec async/await
async function addRating(userId, movieId, rating) {
    const response = await fetch('http://localhost:8000/ratings/', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            userId,
            movieId,
            rating,
            timestamp: Math.floor(Date.now() / 1000)

⚙️ Configuration Avancée
Mode WAL pour SQLite
Pour éviter les verrouillages de base de données, activez le mode WAL dans app/database.py :

python
from sqlalchemy import event
from sqlalchemy.engine import Engine

@event.listens_for(Engine, "connect")
def set_sqlite_wal(dbapi_connection, connection_record):
    cursor = dbapi_connection.cursor()
    cursor.execute("PRAGMA journal_mode=WAL")
    cursor.execute("PRAGMA synchronous=NORMAL")
    cursor.close()

🐛 Dépannage
Erreurs Courantes
Erreur	Cause probable	Solution
database is locked	Concurrence d'écriture	Activer le mode WAL (voir Configuration Avancée)
no such table	Tables non créées	Vérifier Base.metadata.create_all(bind=engine) dans main.py
Foreign key constraint failed	movieId inexistant	Créer d'abord le film avant les notes/tags
Duplicate entry	movieId déjà existant	Utiliser un ID unique ou méthode PUT pour mise à jour
ModuleNotFoundError	Import incorrect	Utiliser imports relatifs: from .database import Base
Connection refused	Serveur non démarré	Lancer uvicorn app.main:app --reload
